# OSD Font Studio

Редактор символов OSD-шрифтов для Betaflight. Работает полностью в браузере,
без сервера и без сборки — чистый HTML/CSS/JS (ES-модули).

## Возможности

- **SD-режим** — MAX7456, 256 символов 12×18, 2 бита на пиксель. Импорт/экспорт `.mcm`.
- **HD-режим** — DJI/HDZero/Walksnail, до 512 символов 24×36. Импорт/экспорт `.bmp` (24-бит, серый 127,127,127 = прозрачный).
- Универсальный `.png`-спрайт-лист (16 колонок, реальная альфа-прозрачность) — удобно доработать в Photoshop/Aseprite и вернуть обратно.
- Свой `.json`-проект — чтобы сохранить работу и продолжить позже.
- Кисть, заливка, пипетка, зеркало по горизонтали/вертикали, инвертирование, сдвиг символа, undo/redo, зум.
- При первом открытии автоматически подгружается стоковый шрифт Betaflight (`default.mcm`) — редактировать можно сразу, без импорта.

## Стоковый шрифт (attribution)

`assets/fonts/betaflight-default.mcm` — это официальный `default.mcm` из
`resources/osd/2/` репозитория [betaflight-configurator](https://github.com/betaflight/betaflight-configurator)
(лицензия GPL-3.0). Взят как есть, без изменений, только для удобного старта
редактирования. Если планируешь публично раздавать переработанный шрифт —
стоит сохранить упоминание источника рядом с файлом.

## Локальный запуск

Любой статический сервер подойдёт, например:

```bash
npx serve .
# или
python3 -m http.server 8000
```

Открыть `index.html` напрямую через `file://` тоже работает почти всегда,
но некоторые браузеры блокируют `fetch`/модули с `file://` — сервер надёжнее.

## Деплой на GitHub Pages

1. Создать репозиторий (или использовать существующий) и залить туда содержимое этой папки.
2. В настройках репозитория → **Settings → Pages** → Source: `Deploy from a branch`,
   ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен на `https://<username>.github.io/<repo>/`.
4. На своём сайте можно просто дать ссылку на этот адрес — отдельный деплой,
   без интеграции в основной проект.

Никаких API-ключей, бэкенда или сборки не требуется — статика как есть.

## Структура проекта

```
index.html
css/style.css
js/
  constants.js       — режимы SD/HD, размеры символов
  state.js           — состояние проекта, undo/redo
  editor.js          — canvas-редактор одного символа
  sheet.js           — обзорный лист всех символов
  formats/
    mcm.js           — .mcm (MAX7456 SD)
    hdbmp.js         — .bmp (HD, 24-бит)
    png.js           — .png спрайт-лист
    project.js        — .json проект
  main.js            — склейка UI
```

## Формат пикселя

Внутреннее представление — 3 состояния: чёрный / белый / прозрачный.
Для SD прозрачный кодируется как `01` (двухбитный код MAX7456);
для HD — как RGB(127,127,127) в BMP или альфа=0 в PNG.
